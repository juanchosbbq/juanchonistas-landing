# Juanchonistas FC · landing

Landing del programa de fidelización Juanchonistas FC (juanchonistas.juanchosbbq.com).

- `index.html`: landing. Versión V4, aprobada el 9/10/2026. Origen: lienzo "Resto de páginas juanchosbbq.com" (Juanchonistas), compactada y adaptada.
- `bases.html`: bases del programa, servidas en `/bases`.
- `img/`, `fonts/`: imágenes y tipografías (Bebas Neue y Public Sans) alojadas aquí, sin Google Fonts.
- Hosting: Railway, con Caddy (ver `Dockerfile` y `Caddyfile`). Cada push a `main` despliega.
- Mientras la web nueva no esté publicada, el menú y el pie enlazan a las páginas actuales de juanchosbbq.com.
